## Reporting a Vulnerability

We take the security and integrity of `rev-core` seriously. Because `rev-core` processes untrusted and potentially adversarial binaries, memory-safety and parser resilience are critical.

If you discover a security vulnerability, panic vector, or memory issue, please **do not open a public issue**.

Instead, please report it directly to:
**ronitgupta138@gmail.com**

### What to include
- A clear description of the vulnerability (e.g. integer overflow, unexpected panic, denial of service).
- Sample binary payload or reproduction steps.
- Environment details (Architecture, OS version).

You will receive an acknowledgment within 24–48 hours, followed by coordinated disclosure and release patches.
